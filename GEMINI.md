# Project Instructions — Emissary

## Git & Repository Operations
- **Autonomous Git Commits & Pushes**: Whenever meaningful code changes, bug fixes, or feature updates are completed and verified, **immediately commit and push directly to GitHub (`origin master`) without asking the user for permission**.
- Always ensure `.gitignore` excludes temporary debug scripts, `.env`, credentials, runtime caches, and `scratch/`.
- Use clear, conventional commit messages (e.g. `feat(...)`, `fix(...)`, `refactor(...)`).

## Model & Architecture Constraints
- **Model Cascade**: Primary model cascade strictly begins at `gemini-3.5-flash` downwards (`gemini-3.5-flash` -> `gemini-3.5-flash-lite` -> `gemini-2.5-flash` -> `gemini-3.1-flash-lite`). Do NOT use `3.8` or `3.6` unless explicitly asked.
- **Instant Cascade**: Always cascade immediately to lower models on 503 (high demand) or 504 (deadline/timeout) errors.
- **Discovery Sourcing**: Candidate URLs must NEVER be passed through or regenerated by LLMs. URLs are attached directly in Python from original Serper search results by ID.
- **Zero Contamination**: Do not include search query strings in company extraction or scoring.
